## 📌 About Me
- Hello! I am a Management Information Systems student and a passionate software developer focusing on data engineering and backend data architectures. My technical stack heavily revolves around Python and SQL, with a deep drive to build scalable systems and robust data pipelines. I am the creator and lead developer of Project ACE, an open-source real-time global data terminal featuring specialized modules like LOVELOCK, CURIE, and DOPPLER. I continuously expand my expertise in database management and system architecture, bridging the gap between raw data and actionable solutions.


## 🧠 My Focus Areas
- Data Engineering & Backend Architecture: Designing scalable data pipelines, optimizing relational databases (SQL Server), and developing robust backend systems (Python). Spearheading the architecture and deployment of Project ACE, an open-source real-time global data terminal.
- Technical Project & Ecosystem Management: Directing the Claw Entertainment brand ecosystem. Overseeing end-to-end digital projects spanning advanced AI system modeling (Cassandra AI), interactive software development (Talonn Interactive), and AI-integrated audio production (HollowPurple Music).
- Narrative Design & Creative Strategy: Applying analytical structuring and logical flow to complex digital storytelling. Designing immersive, character-driven narrative frameworks and interactive experiences (including expansive IPs like OMNI'APEX and the Evidence? series featuring Iya).
- System Optimization & Hardware Configuration: Configuring high-performance hardware environments, troubleshooting IT infrastructure, and fine-tuning technical peripherals to ensure maximum efficiency and peak operational performance.
